
# 🛡️ Cybersecurity Lab Setup | Week 01

**Networkwalks Cybersecurity Internship – Batch B084B**

## 📌 Project Introduction

As part of my first week at Networkwalks, I worked on setting up a virtual cybersecurity lab environment using Oracle VirtualBox and Kali Linux.

The purpose of this project was to understand virtualization, configure a virtual network, and prepare a Linux-based environment for future cybersecurity practicals.

## 🎯 Project Goals

- Build a virtual lab environment.
- Install and configure Kali Linux.
- Understand VirtualBox networking.
- Configure a custom NAT Network.
- Learn static IP configuration.
- Understand VM snapshots and recovery.

## 🧰 Tools & Environment

| Tool | Purpose |
|---|---|
| Windows 10 | Host Operating System |
| Oracle VirtualBox | Virtualization |
| Kali Linux | Guest Operating System |
| 7-Zip | Archive Management |
| NAT Network | Virtual Networking |

## ⚙️ Lab Configuration

| Configuration | Required Setting |
|---|---|
| Network Type | NAT Network |
| Network Subnet | 10.0.0.0/24 |
| Kali Linux IP | 10.0.0.2/24 |
| Default Gateway | 10.0.0.1 |
| DNS Server | 8.8.8.8 |

## 🔬 Practical Implementation

### 1. Virtualization Setup
Installed Oracle VirtualBox to create and manage a virtual machine.

### 2. Kali Linux Environment
Imported and started Kali Linux inside VirtualBox.

### 3. Network Configuration
Worked with NAT Network settings using the required subnet 10.0.0.0/24.

### 4. IP Configuration
Worked on configuring the Kali Linux network interface with the required static IP settings.

### 5. VM Snapshot
Created a virtual machine snapshot to understand how system states can be saved and restored.
